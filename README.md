# Netflix Content Analysis Dashboard using Power BI

An interactive Netflix Content Analysis Dashboard developed using Microsoft Power BI to explore and analyze Netflix content based on content type, age groups, genres, release trends, countries, and cities.

## Project Overview

This project focuses on transforming Netflix content data into an interactive dashboard that provides a clear view of the platform's content distribution and trends.

The dashboard uses visual analytics to understand the composition of Movies and TV Shows, analyze content across age groups and genres, and explore release-year and geographic patterns.

## Objectives

- Analyze the distribution of Movies and TV Shows.
- Understand content distribution across different age groups.
- Analyze genres based on average release year.
- Examine director trends across release years.
- Identify the first country represented in the dataset.
- Explore content across different cities.
- Provide interactive filtering for better data exploration.

## Dashboard Features

### 1. Content Overview

The dashboard provides key performance indicators for:

- Total number of shows
- Total Movies
- Total TV Shows
- First country
- Number of cities

### 2. Content Distribution by Type

A donut chart compares Movies and TV Shows.

- Movies: 724 (72.4%)
- TV Shows: 276 (27.6%)

This provides a quick understanding of the overall content composition.

### 3. Content Distribution by Age Group

A horizontal bar chart shows the number of shows associated with different age groups.

This helps compare how Netflix content is distributed across different audience classifications.

### 4. Genre Analysis

The dashboard visualizes the average release year across different genres, including:

- Crime
- Action
- Drama
- Documentaries
- Sci-Fi
- Romance
- Comedy
- Thriller
- Children & Family
- Horror

This helps identify how the release period varies across different content categories.

### 5. Release Year Analysis

A line chart displays the count of directors across release years.

This allows users to observe changes and trends in director representation over time.

### 6. Interactive Filters

The dashboard includes interactive filters for:

- Type
  - Movie
  - TV Show

- City
  - Chennai
  - Coimbatore
  - Cuddalore
  - Dindigul
  - Erode
  - Kanchipuram
  - Karur
  - Madurai
  - Nagercoil
  - Namakkal
  - Salem
  - Thanjavur
  - Tiruchirappalli
  - Tirunelveli
  - Vellore

These filters allow users to explore the dashboard based on selected content types and cities.

## Key Insights

- Movies represent the majority of the content in the analyzed dataset, accounting for 72.4% of the total shows.
- TV Shows account for 27.6% of the total content.
- The dataset contains 1,000 shows in total.
- India appears as the first country in the analyzed dataset.
- The dashboard covers content across 15 cities.
- Release-year analysis shows variations in director counts across different years.
- Genre analysis highlights differences in average release years across content categories.
